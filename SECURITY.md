# Security

Found a security problem in Hopper or usehopper.dev (for example a way to make the server run,
read or write something it shouldn't)? Please don't open a public issue. Report it privately with
GitHub's [private vulnerability reporting](https://github.com/hopper-rust/hopper/security/advisories/new),
or message a maintainer on [Discord](https://discord.gg/kKqTbptz2T).
