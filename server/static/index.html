Hopper

Port Fabric client mods to Horizon.

Paste a Modrinth link. Hopper checks the license first, then reads the names the mod uses and says which parts map to Horizon's mod API. The starter project also converts what it can of the mod's public source code, only when the license allows it. Hopper is not an official Horizon project. How it works

Try No Mining Cooldown, CommandKeys or Sodium.
